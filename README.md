# DeepwellGuides — Portal Modular de Guías EVE Online

Aplicación web construida con **React + TypeScript + Vite + Tailwind CSS**.

## Características incluidas
- **Estética industrial en escala de grises y oro metálico** con logotipo personalizado (`public/logo.svg`).
- **Filtro global de Clon (`Todos`, `Solo Alpha`, `Omega`)** sincronizado en todas las secciones del portal.
- **Datos contrastados:** límites reales de clones Alpha (5M / 20.5M SP), recargo del +2% en industria, advertencia sobre *Ice Harvesting II* y la excepción oficial del **Mining Barge Expert System** para volar barcazas T1 como Alpha.
- **6 Módulos técnicos:** Visión General, Mecánicas *Catalyst* (críticos y residuo), Catálogo de Naves ORE, Biblia de Skills, Protocolo Null-Sec, Mini-guías especializadas (Gas, Hielo, Mercoxit) y Fittings listos para copiar en formato EFT.

## Cómo ejecutar el proyecto localmente

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```
